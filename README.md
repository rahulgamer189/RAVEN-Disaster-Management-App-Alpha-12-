# RAVEN — Disaster Management & Emergency Response App

RAVEN is a disaster management and emergency response application
designed to provide communication and emergency support when
conventional networks are unavailable.

## 🚀 Key Features

- Bluetooth Mesh offline communication
- SOS emergency alerts
- Offline maps and navigation
- Location sharing
- Rescue tracking
- Nearby hospitals and refuge camps
- AI emergency assistant

## 🎯 Vision

Communication should never stop when people need it the most.
